Windows Sandbox configurator

Pick a profile, tweak the settings, and download a real .wsb file. Everything happens in your browser: nothing you type is uploaded anywhere, and there is no server behind this page.

This page does not run a sandbox. It only generates the configuration file. To use the file you need Windows 10/11 Pro, Enterprise, or Education (not Home), with virtualization enabled and the Windows Sandbox feature turned on. A generated file still needs a mapped host folder to actually exist on the machine that launches it — this page cannot check that for you.

Profile

Changing the profile resets the options below to that profile's values. Untrusted is the locked-down default.

Options

Below 2048 MB, Windows Sandbox raises it to 2048 automatically. This page does the same, with a warning.

A single command that must exist inside the sandbox. For multi-step setup, map a script file in and run that instead.

Mapped folder (optional)

Must be an absolute Windows path. Env-var paths such as %USERPROFILE%\Downloads\untrusted work on Windows 11 23H2 and later.

Never map a whole user profile or a folder with credentials into a sandbox running untrusted software, and never map one writable. Read-only, one folder, one job.
